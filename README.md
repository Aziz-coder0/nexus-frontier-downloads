# Nexus Frontier downloads

Nexus Frontier is the mobile reader for the Nexus Frontier campus publication. Abdul A. Omar develops the app.

- [Download the latest release](https://github.com/Aziz-coder0/nexus-frontier-downloads/releases/latest)
- [Read the journal](https://nexus-publication.ccasso.tech)

## Install

On Android, download the APK and open it to install. Keep the existing app installed when applying an update so your saved stories and preferences stay on your device.

On iPhone, the sideload IPA requires [Sideloadly](https://sideloadly.io/) on a computer and must be signed with your Apple ID before installation.

Install 1.3.0 manually to enable in-app checks for future releases.
